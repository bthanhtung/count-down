# Đếm ngược Tết

Còn bao lâu nữa là Tết? — **[live demo](https://tungbt-count-down.netlify.app/)**

- Đếm đến **Mùng 1 Tết Nguyên Đán** (bảng âm lịch 2026–2032) hoặc **Tết Dương lịch**, luôn tính theo giờ Việt Nam (GMT+7)
- Số lật từng chữ, thanh tiến độ từ Tết năm ngoái, lời chúc xoay vòng
- Hoa mai rơi, đèn lồng đung đưa, pháo hoa (bấm nút hoặc chạm vào bất kỳ đâu); 10 giây cuối tự bắn, 3 ngày Tết đổi sang lời chúc
- `?mode=duong` mở thẳng Tết Dương lịch · `?demo=10` giả lập còn 10 giây để xem màn giao thừa
- Gửi cho bạn bè bằng Web Share (điện thoại) hoặc chép lời nhắn kèm link

HTML, CSS, JavaScript thuần — không build, không framework.
