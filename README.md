## Có gì

- Đếm đến **Mùng 1 Tết Nguyên Đán** (bảng âm lịch 2026–2032) hoặc **Tết Dương lịch**, luôn tính theo giờ Việt Nam (GMT+7)
- Số lật từng chữ, thanh tiến độ từ Tết năm ngoái, lời chúc xoay vòng
- Hoa mai rơi, đèn lồng đung đưa, pháo hoa (bấm nút hoặc chạm vào bất kỳ đâu); 10 giây cuối tự bắn, 3 ngày Tết đổi sang lời chúc
- **Gửi cho bạn bè:** Facebook, Messenger, Zalo, Telegram, X, chép link (điện thoại có thêm bảng chia sẻ của máy); dán link sẽ hiện ảnh xem trước `og.png`

## Chạy trên máy

HTML, CSS, JavaScript thuần — không build, không framework.

```sh
git clone https://github.com/bthanhtung/count-down.git
cd count-down
npx serve .        # hoặc mở thẳng index.html bằng trình duyệt
```

Muốn tự đăng lên mạng: kéo thả cả thư mục vào [Netlify Drop](https://app.netlify.com/drop), hoặc bật GitHub Pages cho repo. Nhớ đổi `SITE` trong `app.js` và các thẻ `og:` trong `index.html` sang domain của bạn.
